# Mutual Fund Analysis & Performance Ranking

## Overview

Analyzed approximately 2,500 mutual funds to compare performance and identify top-ranked funds using multiple financial metrics.

## Tools

Python, Pandas, NumPy, Power BI, DAX

## Key Analysis

* Cleaned and transformed mutual fund data
* Applied Min-Max normalization
* Created a composite score using returns and expense ratio
* Ranked funds and identified the Top 30
* Compared 1-Year Return, 3-Year Return, and Expense Ratio
* Built an interactive Power BI dashboard

## Dataset

The original dataset CSV file is **not included** in this repository. The repository contains the analysis code, ranking methodology, dashboard, and project documentation.

## Key Skills

Python • Pandas • Data Cleaning • Data Transformation • Normalization • Ranking • Power BI • Data Visualization
